# DYFI Pinarayi Blood Donor Management System

A modern, production-ready web application for managing blood donors under the DYFI Pinarayi Block Committee.

## 🚀 Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **UI Components**: shadcn/ui
- **Backend/Auth**: Supabase
- **Animations**: Framer Motion
- **Forms**: React Hook Form + Zod
- **Icons**: Lucide React

## ✨ Key Features

- **Mobile-First Design**: Optimized for healthcare usage on the go.
- **Dashboard**: Real-time statistics and emergency search.
- **Donor Management**: Detailed profiles with blood group, location, and donation history.
- **Committee Hierarchy**: Manage Megalas and Units seamlessly.
- **Real-time Filtering**: Search by blood group, location, name, or phone.
- **Exporting**: Generate PDF and Excel reports for offline use.
- **Authentication**: Secure admin access via Supabase Auth.
- **Emergency Actions**: Direct Call and WhatsApp integration.
